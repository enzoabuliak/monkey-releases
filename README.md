# Monkey releases

Downloads and the update feed for **Monkey**, an Arc-style browser for macOS built on [Helium](https://github.com/imputnet/helium) (Chromium).

- Download the newest `.dmg` from [Releases](../../releases). Builds aren't signed with an Apple Developer ID yet: the first time, open Monkey, click **Done**, then **System Settings → Privacy & Security → Open Anyway**.
- `mac/appcast-arm64.xml` is the update feed Monkey checks; updates are verified with an EdDSA signature.

Monkey is free software under the GNU GPL v3, like Helium and Chromium. Its source isn't public yet; if you have a copy of Monkey, ask the maintainer and you'll get the corresponding source.
